# 使用说明

这是 **B0 长视频主脚本**（3–5 分钟）。视觉全部用"**免费工具 + 自己截图**"搞定；极个别概念画面用**即梦 AI**（免费额度）补。

**制作流程**：
1. 按「素材清单」预先准备 → 存到 `/video-assets/B0/`
2. 按脚本里的 `🎬` 提示进剪映拼接
3. 配音：把文稿贴进 Fish Audio，用你的克隆音色生成 mp3
4. 剪映里音频拖到底轨，画面按秒对齐
